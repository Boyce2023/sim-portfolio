# 软件与存储历史拆解接续

Codex分析意见：五份全文已读。仅继承问题和研究结构，所有历史行情、证券数字、管理层原话与判断须在业务使用前重新验证。原文的买入等级、技术止损或价格跌幅不得转成最新慢账卖出门。

## APP

- MAX库存与AXON预测形成双边数据飞轮；量增依赖同ROAS下预算扩张，不可把提价当增长引擎。
- 剥离低毛利游戏业务使利润率口径跃迁，不能全归因经营杠杆。
- 模型迭代节奏是核心脆弱点；首次跳涨可见高边际利润但无法预知后来电商放量和业务剥离。

待解：take rate归属是否把MAX mediation与DSP收入混同需一手重核。；交割表述内部冲突：宣布时间、签约与完成时间未严格分开。；eCPM、客户留存、模型改进持续性和非游戏实际贡献缺少颗粒度。

## CRM

- cRPO领先于收入；必须分开Informatica并表与有机增长。
- Agentforce paid deals、ARR、AWU与合并Data Cloud口径反复切换，不可互当同一指标。
- AI替代席位叙事风险与当季财报兑现是两条线；回购需扣债务利息影响。

待解：真实生产付费比例、AWU美元折算、独立seat增长尚缺。；自由现金流下降及发债回购每股价值需拆解。；文中用卖方/远期PE PEG作估值，与现行G来源约束冲突。

## DUOL

- 先核回测原记录：八月样本拒买而五月样本高信心买，不能把两者混作一次错误。
- DAU减速与AI替代叙事分别冲击增长和倍数；利润改善不能排除估值尾部风险。
- 课程生成成本降低不等于课程护城河增强；通用模型可复制性须持续复核。

待解：大量后续季度与AI事件仅WebSearch，未一手核验。；跌幅口径不同：高点到谷底、收盘到一年后不可混用。；声称估值压缩贡献比例未作归因模型，不可转成事实。

## IREN

- 矿工转AI云为资本密集交付链：锁电→建机房→GPU融资→客户验收→收入。
- 已签ARR、在营ARR、确认收入分别列账；挖矿主动退出会制造收入下行噪音。
- 负FCF不是单独否决；客户信用、预付款、融资缺口、稀释速度与交付风险更关键。

待解：20%合同预付款与96% GPU capex覆盖可能不同分母，需核口径。；EV与类债务、每MW成本和股数变动未独立核对。；报告含卖方预测/评级目标价，仅留作历史立场，禁止进入现行估值链。

## MU

- DRAM/NAND分拆，HBM挤占晶圆、洁净室与新厂周期是原论点的物理约束。
- 三次跳涨提示：剔税和库存一次收益；beat-and-raise不足以判持续，合约覆盖深度更重要。
- 长期SCA地板价与覆盖份额决定周期底部中枢，但原文多为管理层主张。

待解：极高收入/毛利率及价格数字是历史文件声明，尚未独立核验。；分析师发言未被反驳不能算公司确认。；CXMT扩产、KV缓存架构压缩、SCA合同执行与覆盖需独立验证。；MU_model读取失败，不能算已覆盖模型。
