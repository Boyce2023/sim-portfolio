# case: 扫描理由"出处洗白"——自媒体推测被嫁接官方公告编号

**日期**: 2026-09-01
**decision_type**: buy / research_verification
**rule_id**: D2, S5, T13, Gate7
**ticker**: 002138 顺络电子, 300433 蓝思科技, 300328 宜安科技

## 发生了什么

8/31 astock_v3 扫描的 Step2 深研底稿给顺络电子裁 A- probe，理由第一条是:
"TLVR电感已批量供应英伟达GB200/Rubin平台头部功率模块客户及云厂商
（出处：公司2026-08-05/06投资者关系活动记录表）"

9/1 我据此建仓 7800股 @47.25（约36.9万）。建仓后做事实核验，下载该记录表官方PDF
（编号2026-017，2026-08-07披露）全文检索：

**「英伟达」「NVIDIA」「GB200」「Rubin」「云厂商」——一个词都没有。**

公司原文只有："TLVR拓扑结构产品主要用于AI服务器的xPU芯片方面……已实现产品的批量化供应"
（不点名客户）。"深度适配英伟达Rubin平台""订单排至2028年"实际出自东方财富财富号
某自媒体账号的个人观点文（文末声明"仅代表作者个人观点"，且该文自身未引用任何公告）。

**同日另外两例同型错误**（候选深研 agent 核出）：
- 蓝思科技"独供约70%折叠iPhone UTG订单" → 媒体传闻，公司投资者关系部明确
  "涉保密协议不予置评"，即公司拒绝确认
- 宜安科技"苹果折叠屏独家隐形冠军" → 来源是雪球荐股帖（标题"2026年业绩要炸"）

## 病理：为什么这类错误最危险

普通的编造容易识别（没有出处）。这类错误的形态是**真实存在的官方出处 + 自媒体的内容**——
citation 本身可以点开、编号真实、日期真实，所以看起来比无出处的说法更可信，
反而更容易通过审查。称之为"出处洗白(reason laundering)"。

我的失误不是"相信了agent"，是**违反 D2/S5**：agent 输出默认 low confidence，
进正文（更别说进交易）前必须交叉验证。我把一份未验证的二手底稿直接当成了建仓依据。

## 代价

T+1 规则下当日无法卖出——用未验证理由建的仓，发现证伪的当天改不掉，必须扛一夜。
**错误的建仓决策没有当日撤销键。**

## 规则（已生效）

1. ⛔**任何 agent 底稿里"点名大客户/独供/份额/订单排产"的断言，进入建仓 reason 前必须
   追到一手来源**（公司公告PDF全文检索、交易所互动易、公司IR记录原文）。
   追不到 = 该断言不得写进 reason，也不得作为 conviction 的加分项。
2. ⛔**自媒体来源清单（一律标"未证实传闻"，不得作论据）**：东方财富财富号、雪球个人帖、
   微信公众号荐股文、"XX投研""XX研究"类无署名机构号。
3. **判断句式**："公司说X用于Y领域" ≠ "公司说X供货给Z客户"。前者是产品用途，
   后者是客户关系，扫描agent经常把前者写成后者。
4. 核验优先级：**先核最能支撑买入叙事的那一条**（题材锚点），不是从头核到尾。
   锚点倒了，后面的都不用看。

## 案例4: 2026-09-03 中一科技/雄帝科技 代码-名字-thesis 三方错配
- 09-02 深扫队列记录: "中一科技 300546 ... 9/1固态链普跌日唯一逆势+6.1%(17.41→18.48), 超薄锂箔加工壁垒, 与铜箔游资波(诺德)同题材"
- 实证(09-03 ak kline): 300546=雄帝科技(数字身份/证卡), 9/1 确为 +6.15% 17.41→18.48; 中一科技=301150(锂电铜箔), 9/1 为 -5.76% 收38.12
- 结论: 价格事实属于A股票, 名字与产业thesis属于B股票, 被缝合成一条候选。若不核代码就深扫, 会拿铜箔逻辑去研究一家做电子证照的公司。
- 防线: 任何进入 deepscan_queue / probe 的条目, 建仓前必须用 `ak price <code>` 核"代码→名字"一致, 再核"名字→thesis"一致(公司→项目→数据 三元组, O2)。
