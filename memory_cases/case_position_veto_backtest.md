## Case: 位置/盘中量比不否决买入(SOP R2/R5)

**情境(08-06~08-10连环事故)**: 扫描系统曾用"距25日高点太远"和"盘中量比过高/过低"直接否决买入候选。08-06 point-in-time双段回测证明"距突破点位置"门槛拖累收益——A段-0.51pp，B段-4.37pp，两段都垫底。同时期实测盘中用量比外推全天量比会高估2.5~2.9倍(3.87 vs 收盘实测1.53)，用这个虚高数字否决买入=误杀真信号。

**规则**: ①位置(距25日高)不否决买入，只用于仓位分档(距突破越远仓位越轻) ②盘中量比不可用于任何否决类判断，收盘后才能用真实量比做天量否决(vr60≥3.0)。

**⚠️命名提醒**: 这两条规则编号是astock_scan_sop.md自己的R2/R5，和strategy_astock.md §1的R2(仓位硬顶表)/R5(If-Then盘中不可修改)是两套完全不同的编号系统，同名不同义——读的时候看清楚是哪个文件的R系列，别混用。

**教训**: "看起来像技术面否决"的规则，backtest之前先假定它是错的——过去两个月里两条独立的position-veto规则都被实证推翻。
