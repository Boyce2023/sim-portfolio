# 四进五接力定版与二进三全因子证伪淘汰五年回测总报告

`回测总结论：四进五满120分高严档作为纯单仓第3顺位正式定版移交实盘；二进三在773个切片下胜率封顶47.8%且去极值净值倒亏10%，塞入组合反抢高胜率槽位，必须永久淘汰。`

回测环境基于 Python 3.13 与沪深全市场A股日线数据。时间跨度为2022年1月至2026年11月共五年全周期。严格执行单仓轮动复利、剔除一字不可买样本、计入炸板与千2交易摩擦、扣除同期沪深300涨跌幅核验净超额。

## 一、核心结论与决策定案

1. **四进五满120分高严档定位**：专吃全场最高连板处于4板或5板的新周期破局独苗，在09:25竞价涨2.0%至7.5%分歧区间直接买入。纯增量交易19笔，单笔均赚13.79%，独立增量净值8.11倍，去前三妖股净值2.32倍，最大回撤24.5%，近三年胜率64%以上。
2. **纯单仓顺位增强实证**：将四进五满120分排在纯单仓第3顺位（高标首阴 ＞ 三进四 ＞ 四进五120分 ＞ 一进二），五年纯单仓净值由39818.98倍直接推升至91395.80倍，最大回撤保持29.22%零放大。在此基础上纳入超跌橡皮筋撬板满165分作为第4顺位，推升至五策略纯单仓187笔总胜率67.91%，累计净值达136325.63倍，最大回撤稳于29.22%。
3. **二进三全因子彻底证伪淘汰**：对二进三全量374个因子切片扫描，无一能突破48%胜率瓶颈。最优打分卡去前三妖股净值仅0.90倍，留一法样本外仅0.61倍。塞入组合后反抢三进四与高标首阴仓位，导致组合去极值净值暴跌56%，全周期无独立正超额，定案永久淘汰。

## 二、四进五适用周期与红线禁区

1. **适用周期**：市场最高连板恰为4板或5板的情绪上升期与混沌破局期。全场仅有1只或处于竞价第一名的4板独苗，开盘涨幅在2.0%至7.5%之间，享受全市场接力资金的垄断溢价。

   * 头顶已有6板及以上老龙头压制的中位跟风四板。五年全样本480笔，胜率仅38.1%，单笔均亏1.79%。
   * 09:25竞价一字涨停顶死，或高开超7.5%缩量秒板。
   * 昨日四板午后曾开板炸板的尾盘弱板。
   * 近90日存在减持立案退市等毒丸公告，或近10日存在个股监管函。
   * 09:25起算双严重异动较紧剩余空间不足12%的品种。

## 四、四分支卖出与高标真阳原地移交机制

1. **分支A（未封五板收真阳原地移交）**：买入当日若未封住五板，且自身为最高四板、收盘高于开盘收真阳线、换手不超35%、无毒丸无监管，当日不割肉。原地转为高标首阴逻辑持有至次日。次日开盘若深跌超3.5%则竞价止损，否则持有博全天反包。反包封板则转入连板锁仓，未封板则收盘清仓。
2. **分支B（未封五板非真阳移交）**：当日未封板且不满足真阳移交条件。若收阳线且次日高开满0.5%则观察至收盘，否则次日09:25竞价直接离场。
3. **分支C（封死五板连板主升）**：严禁挂93%双严重异动提前限价止盈单。实测挂93%单会使湖南发展、赣能股份、美邦股份等大主升收益腰斩。连板期间每日执行13:45午后护利，盘中冲高满8.5%回落破5.0%且未封板则立即止盈。
4. **分支D（五板后首次断板）**：享受1次真阳断板免死，断板日收红盘真阳线多拿一天，次日不反包涨停收盘走。断板收阴线当日收盘全部清仓。

## 六、二进三全因子证伪淘汰完整证据

对二进三共374个因子切片及与四进五合并773个切片全量回测，确认以下证伪事实：

1. **胜率上限无法打破**：全量374个二进三因子组合中，无论如何叠加概念评分、主力净买、身位优势或盘口结构，全周期胜率最高仅48.53%，均值在44%至47%之间游荡。
2. **极度依赖前三大妖股**：二进三最优打分卡（Thr 108）全周期68笔名义净值5.49倍，但前三大妖股（信隆健康赚92.68%、山西高速赚70.83%、长城军工赚57.73%）贡献了绝大部分利润。剔除前三大妖股后，单仓净值骤降至1.057倍；在300次权重随机抖动测试中，去前三净值中位数仅0.728倍（倒亏27.2%）。773个切片下平均去极值净值仅0.90倍。
3. **样本外表现彻底失效**：在5折留一法样本外盲测中，二进三全量样本外净值仅0.61倍，5个测试年份中仅2年盈利，最大回撤高达67.1%，证明其高收益纯属历史样本内过度拟合。
4. **单仓组合排斥冲突**：将二进三强行塞入纯单仓组合时，因其出枪频繁且胜率低下，频繁抢占高标首阴与三进四的高确定性槽位。导致组合单仓净值由39818倍跌落至25960倍至32308倍，去极值净值缩水超过56%，且最大回撤由28.87%恶化至33.05%。因此二进三永久剔除出生产策略库。
