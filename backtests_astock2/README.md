# 二号席短线量化回测目录说明

本目录为二号席 astock2 专属回测工作区。

## 目录规范与防撞纪律
1. 脚本命名规范：所有回测脚本统一以 bt2 开头，例如 bt2_factor_decay_v1.py。
2. 临时文件隔离：所有运行时生成的临时中间文件统一放置于 /tmp/astock2_ 前缀路径下。
3. 数据库只读访问：读取本地行情 SQLite 数据库时，连接字符串必须显式声明 mode=ro 只读模式，严禁写操作，杜绝多进程锁表。
4. 共享总账登记：开展回测前必先查阅并登记共享总账 backtests_shared_ledger.md，杜绝与一号席课题撞车。
5. 成果提案流转：回测产出之策略参数与改进建议以提案形式提交一号席，严禁直接修改生产宪法 strategy_astock.md。
