一、缓涨加高增长（30年回测）

1996年至2026年全周期有效的主力底仓策略，在近10年（2016年至2026年）超额收益反而比早周期更高。

这是买250亿美元以上美股最稳且赚大钱的第一主力打法，专门在股价走出1.5年到3年平滑右上角斜率时进场，近10年符合三条硬规则的标的买入后持有3年平均大涨正85.5%（超额正42.2%），持有5年平均大涨正176.9%（翻倍率48.1%），且3年内发生腰斩的概率只有8.1%。

适用环境是全天候牛熊震荡期，尤其在市场害怕高估值而不敢追高真正垄断龙头的阶段表现最好。绝对不可以在能源大宗商品、重资产房地产信托（REITs）和普通公用事业股上使用缓涨策略，这三个行业缓涨3年后跑输标普的概率高达60%到72%。

在股价连续缓涨满1.5年（18个月）后买入，交易守则：

  • 拟合平滑度 R平方 >= 0.75 且区间最大回撤 <= 22%：最重要。暴涨暴跌的股票哪怕过去两年涨得多，未来3年腰斩概率仍高达43.9%；而R平方不低于0.75的平滑缓涨股，未来3年腰斩概率直接压降到8.1%，因为它背后是机构长线资金按季度业绩匀速买进。
  • 真实营收同比增速 >= 15% 且投入资本回报率（ROIC）>= 15%：在已经保证走势平滑的前提下，这两条直接锁死业绩底盘。一旦收入增速掉破10%或者ROIC低于12%，缓涨就是纯粹靠拔估值吹起来的肥皂泡，未来5年净超额会直接转负。
  • 缓涨池里常出现多只候选二选一的情况：第一，看毛利率，必须 >= 55% 且稳中有升（5年毛利标准差小于3%），低毛利代工组装一律排除；第二，看市盈率（PE），最优击球区在 20 倍到 42 倍之间，PE超过42倍后未来5年净超额全部转负；第三，优先选每年净回购注销股本 >= 2% 的公司，剔除每年发期权稀释股本超2%的公司。

卖出守则与持有期：

  • 最佳持有窗口是买入后 1.5 年到 3 年，只要单季营收增速维持在15%以上、毛利率不降，中途出现10%到15%的正常回调绝不提前下车。
  • 触发以下任一条件在当季财报收盘全部卖出：第一，连续两个季度真实内生营收增速跌破10%；第二，静态市盈率被炒到突破行业硬上限（企业软件PS超12倍、医疗器械PE超45倍、消费零售PE超30倍）；第三，管理层突然花超过净资产30%的钱去收购亏损公司，导致ROIC骤降一半以上。

关于策略的延伸与失效预警：

策略的最强延伸是「微亏临近扭亏高增王（NTRA模式）」：有些极品成长股因为前期研发和销售投入大，营业利润率在负15%到0%之间（还没法算正常PE，市销率PS在8到18倍），只要它满足缓涨1年以上 + 毛利率 >= 55% + 营收增速 >= 35%，这就是全市场爆发力最猛的临界点，买入后3年平均暴涨正118.5%，5年平均暴涨正199.3%，胜率高达80.0%。

策略失效与个股暴雷的领先信号：第一，出货量或总交易额还在涨，但单件平均售价（ASP）或综合变现率连续2个季度下滑超50个基点（如当年的贝宝PYPL和隐适美ALGN）；第二，存货周转天数连续2个季度同比暴增超30天，说明业绩是靠给免税店或经销商压货做出来的（如雅诗兰黛EL）。
