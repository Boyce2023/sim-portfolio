五、近5年与近10年暴利新策略（40法则与缩股王）

2016年至2026年（特别是2021年至2026年高利率与AI时代）新崛起的三大暴利策略，专门抓 1 年大涨 30% 到 60%、3 年翻倍甚至翻两倍的超级赢家。

把时间轴切到近10年和近5年，美股生态发生了根本性剧变：传统看市净率（PB）、看普通净资产收益率（ROE）和买低市盈率的策略大幅衰退，取而代之的是三条统治级的新选股规则：第一，「微亏临近扭亏高增王（NTRA与早期特斯拉模式）」，3年平均暴涨正118.5%，5年暴涨正199.3%；第二，「50法则财报跳涨王（APP与ANET模式）」，单季收入增速加营业利润率超50%且跳涨，1年平均大涨正28.9%；第三，「高ROIC净回购食人族（ORLY与AZO模式）」，每年注销股本超3%且账面净资产被买成负数，5年净超额比乱发期权稀释的软件股高出整整46.0个百分点！

三大新策略的买入交易守则：

  • 新策略 A（微亏临近扭亏高增王 · 专抓3年翻倍大黑马）：当一家250亿美元以上公司的**营业利润率处在负15%到0%的微亏临界区**（传统PE算不出来或极高，市销率PS在8到18倍），只要同时满足**毛利率 >= 55% + 单季营收同比增速 >= 35% + 股价已走出1年以上缓涨**，立刻重仓买入。因为55%以上的高毛利意味着一旦收入跨过固定研发和销售费用平衡点，未来8个季度的增量收入会全部变成纯利润，走出3年翻倍到翻两倍的主升浪。
  • 新策略 B（45/50法则经营杠杆跳涨王 · 专抓AI与平台爆发）：在财报披露次日（单日跳涨 >= 6%）买入，硬条件是：**单季营收同比增速 + 营业利润率 >= 45%（最优 >= 50%）**，且**单季营业利润率同比抬升 >= 3个百分点（证明经营杠杆正在暴力释放）**，同时**毛利率 >= 55% 且股本同比稀释 <= 1%**（如2024至2026年的AppLovin、Arista、英伟达、Block）。
  • 新策略 C（高有形ROIC加净回购食人族 · 专抓零回撤慢牛）：很多大牛股因为连续十年拿全部自由现金流回购股票（如ORLY、AZO、MCD、TDG），把账面股东权益买成了负几十亿美元，或者因为早年并购账上挂着巨额商誉（如APH、KLAC、ADI），导致传统软件算出来的ROE为负或偏低。我们直接改看**剔除商誉后的有形资产回报率（Tangible ROIC >= 30%）+ 每年净回购缩股比例 >= 2.5% + 股票期权激励占收入比（SBC/Rev）<= 3%**。

卖出守则与绝对禁区：

  • 卖出点：新策略A与B属于高弹性进攻仓，当单季营收增速掉破20%且营业利润率不再环比扩张时止盈；新策略C属于复利底仓，只要每年还在净注销2%以上股本且ROIC不破25%就一直拿着。
  • 近5年最大禁区（高SBC稀释毒药）：**绝对禁止买入每年股本稀释 >= 3% 且期权费用占营收 >= 12% 的公司**！在2022年至2026年高利率环境下，这类靠发股票期权粉饰Non-GAAP利润的公司，持有3年中位数净超额深亏负25.9%，跑赢大盘胜率只有28.0%到32.9%（如早期的DocuSign、Snowflake、Twilio）。
