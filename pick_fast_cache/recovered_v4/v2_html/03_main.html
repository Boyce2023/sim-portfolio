三、财报拐点加低市盈率（PE小于15倍）

专门在优质大白马遭遇行业短暂逆风或情绪错杀后，抓「业绩拐点加速 + 估值从12倍修复到22倍」戴维斯双击的高赔率策略。

最重要的一条实证铁律：绝不可以闭着眼睛盲买「财报跳涨 + PE小于15倍」！过去30年如果无筛选盲买PE小于15倍的跳涨股，持有5年跑赢标普胜率只有44.6%，近5年更是惨输标普27.3个百分点（若把破产退市股算进去，5年超额几乎归零）。但只要严格加上「剔除周期顶」和「剔除一次性假账」两道硬门，持有3年平均大涨正107.4%（净超额正57.7%），持有5年平均大涨正154.1%（翻倍率高达65.9%）！

在财报披露次日（跳涨确认拐点）买入，交易守则：

  • 规则一（铁律排雷：剔除强周期景气顶）：**过去5年毛利率标准差必须 < 5%，且当前营业利润率所处过去5年分位必须 < 90%，同时剔除航运、原油、炼油、大宗矿产与标准化存储芯片**。大宗商品和存储芯片在行业暴利顶点时EPS最大，PE会被动压缩到2至8倍（如2022年2.3倍PE的以星航运随后暴跌92%，2018年4.8倍PE的美光随后腰斩54%）。
  • 规则二（铁律排雷：现金流防伪与历史体质）：**经营性现金流除以净利润（OCF/NI）必须 >= 0.85，且过去5年中位数ROIC >= 12%**。这一刀直接砍掉全部靠卖子公司、分拆资产、税收冲回或股权公允价值重估做出来的「假低PE」（如2026年三季报看似7至13倍PE的百胜YUM、富达FIS、Zoom、霍尼韦尔HON）。
  • 规则三（进攻确认：真内生拐点与高毛利抬升）：**剔除并购后的单季内生营收同比增速 > 5%（或营业利润同比暴增 > 25%），且优先选毛利率 >= 50% 并开始同比抬升、同时公司在净回购缩股的标的**。满足全部三条后，5年跑赢大盘胜率直接从44.6%飙升至68.3%，翻倍率达65.9%。

卖出守则与持有期：

  • 持有期与止盈点：低PE真拐点股做的是估值与业绩双击，标准持有期为 1.5 年到 3 年。当市盈率从买入时的 10 至 15 倍修复到 22 倍至 28 倍合理中枢，且单季利润增速回落到 15% 常态时，分批止盈换马。
  • 止损与证伪红线：买入后下一个季度如果扣非营业利润重回负增长，或者自由现金流转负、净债务除以EBITDA超过3.5倍（如暴雷计提64亿商誉减值的Fiserv），说明拐点是假脉冲，当季财报日无条件清仓。
