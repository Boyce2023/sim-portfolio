三、历史经典对决：真拐点十倍股（AAPL / MSFT / UNH / URI）vs 价值陷阱（INTC / WBA / FISV）

为什么2012年10.3倍PE的联合健康（UNH）、2014年13倍PE的微软（MSFT）、2016年10.5倍PE的苹果（AAPL）、2016年8.1倍PE的联合租赁（URI）买进去之后5到10年全部涨了8倍到19倍，而同样10倍PE的英特尔（INTC）、沃博联药房（WBA，暴跌85%退市）和费哲金融（FISV，计提64.5亿商誉减值）却让人血本无归？

  • 真拐点的共同基因（高毛利新引擎爆发 + 现金流狂买自家股票）：2012年市场害怕奥巴马医改限制承保赔付率把UNH杀到10.3倍PE，但UNH内部不受赔付率限制的医疗服务科技平台 Optum 营业利润6年暴增近5倍（从12.6亿飙到82.3亿美元），占集团利润比重从14.9%跃升至47.5%；2016年苹果在iPhone 6s库存低谷跌到10.5倍PE（巴菲特首次建仓），随后高毛利的App Store服务收入翻倍，同时靠充沛现金流回购注销了35%股本；2016年联合租赁（URI）在工业低谷跌到8.1倍PE，逆势并购扩充特种设备租赁（毛利率达50%）并注销31%股本，8年暴涨19.1倍！
  • 真陷阱的共同基因（主业被双向抽干 + 巨额资本开支或高杠杆并购失血）：2020年英特尔10倍PE时，7纳米制程难产导致数据中心份额被AMD和台积电抢走，为了追赶不得不每年砸250亿美元建厂，自由现金流从正200亿直接变成负140亿；沃博联药房（WBA）前店零售被亚马逊抢客，后店配药被三大PBM压榨到零毛利，管理层还借百亿高息债去并购亏损诊所，最终巨亏退市。
