# 一进二 V19 硬门槛 `close <= 60.0` 五年 PIT 消融回测报告

## 总结论
**强烈建议保留现行 `close <= 60.0` 硬门槛，不放宽、不删除、不改软扣分。**
1. **绩效全面最优**：在千三（30bps）与千二（20bps）两种摩擦口径下，`Base_le60` 在全五年、近三年、2026 年的胜率、盈亏比、单仓净值、按日等权净值（EQ）、去前三净值与减沪深 300 净超额均排名第 1（30bps 5Y 1S = 307.10x，放开或软扣分后跌至 272.80x~294.64x）。
2. **卡点位置核实**：上游全市场日线及 `build_signals_and_data_pit` 均无 `close <= 60` 预过滤，该硬门仅卡在 `upgrade_1to2_pit.py:685` 与实盘 `fast_1to2_today.py:1136` 的 `gate_ok` 布尔条件内。
3. **高价科技大票非被 60 元误伤**：2025 至 2026 年主板 `close > 60` 非一字首板共 1,339 条，其中 **727 条（54.3%）因 `mcap > 220` 亿被市值门挡掉**（这部分高价大票首板次日二板封板率仅 11.59%，开盘至收盘平均 -0.16%），且科创板 688 与创业板 300 本就不在一进二范围内。
4. **放开触发逆向挤占效应**：无论取消硬门还是改为软扣分，高价低分首板均会进入 `is_buyable_open` 参与竞价排序，实证抢占同板块低价龙头的 `true_buy_rk` 与 `buy_open_lead`（挤出 `000818 航锦科技`、`002510 天汽模`、`603002 宏昌电子`），其中 `Soft_m10`/`Soft_m20` 还把唯一大赚的 `003043 华亚智能`（+9.82%）扣分刷掉而保留两笔大亏单，表现最差。
