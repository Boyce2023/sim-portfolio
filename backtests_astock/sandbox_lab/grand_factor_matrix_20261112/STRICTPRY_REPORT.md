## 二、最终精锐规则卡 (Rule Card)

所有规则均建立在市场微观结构与流动性物理机制之上：

```
========================================================================================
【基础池】(Base Pool, 排除不可逆致命风险)
  1. 连续跌停天数 >= 2 (prev_dt_streak >= 2)
     [物理机制]: 确立极端超跌的技术形态地基，排除单日偶发性回调。
  2. 严格剔除 ST 与退市整理期股票 (name not contains "ST|退")
     [物理机制]: 排除已进入退市整理期或退市警示的僵尸股，杜绝停牌清算血本无归。
  3. 股价 >= 2.00 元 (open_px >= 2.00)
     [物理机制]: 剔除1元面值退市悬崖边缘仙股，避免流动性丧失导致的连续无量踩踏。
  4. 排除重大暴雷公告 (notice_bad == False)
     [物理机制]: 剔除涉嫌财务造假、被证监会立案调查、控股股东占用资金等实质利空。

【精锐规则】(仅2条额外过滤，直击撬板核心胜负手)
  规则 1: 前20个交易日无涨停板 (zt_cnt_pre20 == 0) — 纯超跌反弹，非妖股A杀
     [物理机制]: 妖股高位A杀退潮聚集了极其庞大的追高被套散户，盘中撬板多为主力诱多
                出逃互砍，极易炸板回封吃大面；而无涨停历史的纯超跌股无上方跟风泡沫
                套牢盘，主力撬板吸筹阻力最小。
  规则 2: 昨日全市场跌停家数 >= 20家 (mkt_dt_prev >= 20) — 系统性极端冰点错杀
     [物理机制]: 单一个股跌停多为个股基本面恶化；但在全市场跌停>=20家的极端恐慌日，
                属于系统性流动性踩踏与杠杆强平错杀；超卖到达极致高潮后，系统性情绪
                稍微回暖即可触发强劲报复性反弹。

【买入与卖出执行】(Execution & Sizing)
  买入方式: 盘中跌停撬开买入 (pry_dt)
     [物理机制]: 09:25以跌停开盘 (open <= dt_px + 0.011)，盘中多头主力承接买盘突破
                (high > dt_px + 0.02)，以 round(dt_px + 0.02, 2) 价格限价买入。
  卖出方式: 摸+7%止盈 / 最长持股5天 (tp7_h5)
     [物理机制]: 盘中涨幅触及成本价 +7% 即刻止盈离场；持有满5个交易日未达目标则于
                第5日收盘卖出（若遇跌停封死严格顺延至开板日）。
  同日优选: 10日跌幅最深优先 (-ret_pre10, Bucket 3 标准手册口径)
     [物理机制]: 短期跌幅最深标的空头动能释放最彻底，弹性修复空间最大。
========================================================================================
```

## 五、1000次蒙特卡洛随机对照基准 (Monte Carlo Test)

为严格验证策略超额收益是来自于**选股与时机阿尔法**还是仅仅因为“碰巧在反弹期选了股票”，我们在同等基础池内，按各年份相同交易笔数（2022年8笔、2023年1笔、2024年4笔、2025年1笔、2026年2笔）随机无偏抽取标的，重复执行 **1,000 次** 模拟模拟对照：

| 检验周期 | 随机分布均值 | 随机分布标准差 | 冠军策略实际均笔收益 | 冠军策略在随机分布中的百分位 | 统计显著性 ($\ge 95\%$) |
|:---|:---:|:---:|:---:|:---:|:---:|
| **样本内 (2022-2024)** | +1.90% | 2.61% | **+6.95%** | **98.6%** | **显著通过 ($p < 0.014$)** |
| **样本外 (2025-2026)** | +1.01% | 6.72% | **+4.84%** | **69.0%** | 均值大幅跑赢随机基准，因3笔离散样本方差大 |
| **全五年 (2022-2026)** | +1.74% | 2.38% | **+6.56%** | **98.4%** | **显著通过 ($p < 0.016$)** |

> 随机对照结论证明：基础池中随机撬板的期望收益仅有 +1.74%，且面临巨大的回封断板风险；而精锐策略以 **+6.56%** 的均笔收益处于全市场随机表现的前 **1.6% 顶尖分位**，规则具备压倒性的统计有效性。

## 九、总结与实盘建议

1. **逻辑纯粹性**：跌停撬板不是每天都有的常规武器，而是**极少数全市场系统性暴跌踩踏日的“特种兵反击战”**。本策略五年仅出击16次（年均3次），严格坚守“无高位泡沫 + 全场极度恐慌”的极致窗口。
2. **风险收益比**：通过提高止盈门槛至+7%并配合纯超跌标的的爆发力，在样本内录得92.3%胜率和1.79盈亏比；样本外虽然在2026年遭遇一笔尾盘回封导致的-15.69%亏损，但凭借力聚热能(+23.4%)与恒铭达(+6.8%)的丰厚利润，样本外净值依然坚挺在1.111，全五年净值录得2.635。
3. **实盘落地准则**：
   - 只要昨日全市场跌停家数不足20家，坚决零操作，杜绝逆势盲目撬个股暗雷；
   - 出现前20日有涨停板的标的，无论盘中撬得多么热闹，一律视作诱多飞刀，坚决不接；
   - 买入后次日盘中若冲高+7%坚决按计划止盈兑现，不贪恋连板幻想，确保高资金周转与落袋为安。
