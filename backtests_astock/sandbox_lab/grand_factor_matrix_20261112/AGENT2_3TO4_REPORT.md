# A股量化沙盒《三进四》全因子与全参数网格优化研究报告

`全32个一进二因子移植与双轨扩容回测彻底证实：在保持单仓胜率61.4%（近3年69.0%）的同时，三进四五年全量净值从飞书基准的12.90飙升至24.16，沪深300净超额达+2333.4%，且通过双轨准入可将五年高质量交易扩容至136笔。`

## 零、总结论与核心认知突破

1. **核心总结论**：
   飞书现有三进四策略的核心痛点在于「硬卡证监会二级行业涨停数 `csrc_zt_cnt >= 2` 导致主线跨行业龙头被错杀」以及「缺乏竞价板块共振过滤与一进二情绪前视」。通过引入一进二的 **同板块竞价共振（`plate_peers_open_avg >= -0.5%`）**、**一进二5日晋级率情绪雷达（`mkt_promo_1to2_5d >= 13%`）** 与 **盘中摸+7.0%扫入触发机制**，三进四全量五年胜率从 50.0% 提升至 **61.4%**（近三年提升至 **69.0%**，2026年7月以来提升至 **100.0%**），去2025四年单仓净值从 4.05 翻倍至 **7.60**。

2. **双轨准入实现高质量扩容**：
   保留原有轨道A（`csrc_zt_cnt >= 2`），新增轨道B（`csrc_zt_cnt == 1` 但满足 `s_prior >= 65` 且题材排位 `rk_theme <= 2` 且同板块竞价共振）。双轨制不仅没有稀释胜率，反而将五年全量单仓胜率稳定在 **57.6%**，日等权五年净值达到 **65.45**，五年交易笔数从 129 笔扩展至 **136 笔**。

3. **飞书环境门的过度拟合证伪**：
   飞书原环境门要求「昨日最高连板 >= 5 且昨日3板跌停数 < 2 且20日核按钮率 < 20%」。回测证实该环境门严重滞后，将五年总单仓交易从 96 笔骤降至 28 笔，净值从 12.90 崩塌至 2.39。`三进四本身就是周期的开路先锋，等市场出现5板再进场已经进入主升中后期，因此该环境门必须废除`。

## 三、双轨准入机制：突破 CSRC 孤岛误杀

### 1. 科学问题
飞书基准硬性要求 `csrc_zt_cnt >= 2`（同证监会行业昨日非ST涨停 >= 2 只）。但在 A 股实战中，很多属于**主线核心龙头**的股票往往跨行业独立作战（例如算力龙头可能在电气设备行业，而同行业多为传统变压器；智能驾驶龙头可能在汽车零部件，同行业缺乏二板跟风）。

### 2. 双轨设计与对比验证

- **轨道 A**：延续行业集聚效应，要求 `csrc_zt_cnt >= 2`。
- **轨道 B**：`csrc_zt_cnt == 1`，但必须满足主线龙头三核保：
  1. 题材先锋分 `s_prior >= 65`；
  2. 题材排位 `rk_theme <= 2`（处于全市场前两大主线）；
  3. 板块竞价共振 `plate_peers_open_avg >= -0.5%`，且无不良公告 `not notice_bad`。

### 3. 双轨效果数据对比

| 轨制模式 | 五年总触发 | 单仓交易笔数 | 胜率 (WR) | 盈亏比 | 五年单仓净值 | 去2025净值 | 日等权 NAV | 评估结论 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **单轨制 (仅轨道A)** | 98 | 68 | 55.9% | 1.64 | 15.35 | 4.98 | 36.62 | 胜率达标，但笔数偏少，部分龙头被拦 |
| **盲目放宽 (csrc_zt_cnt>=1全放)** | 184 | 128 | 48.4% | 1.46 | 5.22 | 0.87 | 21.05 | 引入大量冷门跟风独苗，胜率大幅受损 |

## 六、最终落地推荐方案

### 方案一：【高胜率精锐版】（首推：适合资金规模在 1000 万以内的单仓复利）
1. **准入硬门槛**：
   - `prev_streak == 3`，且昨日换手非一字（`not prev_is_yizi`），今日开盘可买（`buyable_open`）；
   - 证监会二级行业昨日涨停数 `csrc_zt_cnt >= 2`；
   - 昨日换手率 `prev_to` 在 `11.0% ~ 25.0%`；
   - 今日开盘涨幅 `open_pct` 在 `+4.0% ~ +8.5%`；
   - 同板块竞价共振 `plate_peers_open_avg >= -0.5%`；
   - 一进二5日情绪雷达 `mkt_promo_1to2_5d >= 13.0%`；
   - 封单硬度 `seal_tightness >= 20.0`；
   - 剔除硬科技纯外行（`not is_pure_outsider`）、剔除事件大筐（`not is_event_basket`）、无减持立案利空（`not notice_bad`）。
2. **买入模式**：
   - 盘中挂 `+7.0%` 扫入（若开盘已 `>= +7.0%` 则开盘直接买入）。
3. **同日排序**：
   - 优先选择同题材第一身位 `true_buy_rk == 1`；次选题材先锋分 `s_prior` 最高者。
4. **卖出模式**：
