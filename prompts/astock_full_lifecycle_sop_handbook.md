### 1. 无幸存者偏差母体、交叉清洗与真实连板口径

全部 A 股价格与基本面回测严格使用 `/opt/homebrew/bin/python3.13` 解释器，底层唯一价格数据源为 `a_daily.parquet` 拼接 `a_delisted_daily.parquet`（逻辑主键均为 `('ticker', 'date')` 零重复，并非 `ts_code` 与 `trade_date`），严禁任何主会话或子智能体在 A 股场景调用 `yfinance`。现役在市 `00` 与 `60` 主板共 `3,195` 只标的（16,820,850 行日线，跨度 1990年12月19日 至 2026年11月16日），叠加退市主板 `210` 只标的（退市库全市场共 `255` 只、480,688 行日线，注其 `oshare` 列缺失率为 `11.05%` 而核心价量字段缺失率不超 `0.01%`），合并形成 `3,405` 只沪深 10cm 主板 100% 全覆盖研究母体，彻底消除退市股缺失带来的幸存者向上偏差。

```python
# target_dev = 1.00 (10日100%) 或 2.00 (30日200%)
# idx_chg = idx_ref / base_idx - 1.0  (当日基准指数相对基准日的累计涨跌幅)
p_hard = base_close * (1.0 + target_dev + idx_chg)
p_98   = base_close * (1.0 + (target_dev - 0.02) + idx_chg)
p_93   = base_close * (1.0 + (target_dev - 0.07) + idx_chg)  # 93%缓冲止盈单 (即 10日+93% / 30日+193% 叠加指数偏离)
```

### 3. 开工前第 1 道核查门（Q8 Gate 1）

任何新策略研发或旧策略全量重跑前，必须先通过以下 10 项底数信息完备核查门。若存在任意 1 项缺失或校验不通过，立刻停步补齐底层数据后再动代码，严禁带着残缺底座跑回测。

1. **退市与板块母体完备性检查**。确认回测底表同时加载在市股与 `a_delisted_daily.parquet` 退市股，且精确限定目标板块代码前缀（如主板 `00` 与 `60`），核心价量字段（开盘、最高、最低、收盘、成交量、成交额）缺失率不超过 5%。
2. **数据最新基准日硬校验**。实盘或全周期重跑开始前断言 `data_as_of_date == 最新已收盘交易日`，严防日线滞后导致末尾数日信号消失或误判连板天数。
3. **PIT 时点锁死审计**。检查公告 `pub_datetime_cst`（`notices.db` 须严控 `ndate` 防盘后混入）、机构调研 `trade_date_avail`、社区三表真实时间列（`created_time_str`、`pub_time`、`pub_datetime_cst`）、前十大股东 `ann_date` 及 `Elo` 题材状态机是否全部在 `买入日 09:25:00` 之前截断。
4. **量纲与单位同频检查**。确认 `lock_top10` 统一采用百分制（`0` 至 `100`）而非小数制（`0` 至 `1`），`turn` 换手率、`mcap` 总流通市值与 `real_free_mcap` 真实自由流通盘公式无乘除 100 倍错位，复权因子跨除权除息日无缝衔接。
5. **五分钟 K 线覆盖率检查**。验证需盘中分钟级点火或离场的策略（高标首阴、三进四、一进二、超跌撬板）在对应买日点火与卖日判断窗口（`10:30`、`13:45`、`14:30`）上的五分钟 K 线覆盖率达 100%，不接受日线高低价近似替代先后顺序（注二进三 V2.0 固定 `09:25` 竞价买入且未封板持至次日 `15:00` 收盘清仓，封死 3 板或反包后均核查 5 分钟 `13:45` 护利）。
6. **唯一真源与禁用源排查**。确认全脚本无 `yfinance` A 股导入、无 `120.7MB` 旧版与 `0.3MB` 残片 5 分钟库读取、无错读仅含半段 K 线的 `firstboard_5m_5y_pit.db` 充当五年全量 5m 库，并跟踪推进实盘 `fast_1to2_today.py` 从静态行业表切换至 `csrc_industry_pit_clean.csv`。
7. **制度公式至少 3 只停牌公告股反推验算**。上线或重跑涉及双严重异动、涨跌停限制等交易所制度公式前，必先抽取至少 `3` 只历史真实停牌核查公告股，对照 `sh000002` 与 `sz399107` 基准指数反推触发价实现零偏差验算。
8. **按年行数断档排查**。开工必跑按年分组计数 `groupby(year).size()`，排查 `2022年至2024年` 等中段年份是否存在数据源断档或特征大面积空值。
9. **资金交割赶早盘与新代码段核验**。核验 `T+1` 卖股释放资金在时序上能否真实赶上同日 `09:25` 竞价挂单，并显式排查北交所 `92` 新代码段与历史代码复用引发的串票干扰。
10. **龙虎榜买卖方向强校验**。凡涉及龙虎榜席位净买卖因子，开工必校验净买额方向为机构买入减去机构卖出大于 0，绝不允许正负方向写反倒置。
