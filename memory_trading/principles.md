# 元规则层 — A股交易决策原则（情境→行动→原因→证据）

> **定位**: 硬熔断层(`hardgate.md`)之下的第二层。硬熔断是"闸门"，这里是"心智模型"——覆盖到具体情境时才检索，不要求每次决策全读。
> **和 strategy_astock.md 的分工**: strategy_astock.md是**参数/机制**SSOT(仓位%/止损%/评级阈值)，本文件是**判断力/为什么**层。数字对不上以strategy_astock.md为准。
> **规模**: 36条(§A选股10 + §B仓位执行7 + §C持有卖出11 + §D系统边界7 + §E系统性诊断1)，按§分组，在架构目标"元规则层20-40条"区间内。每条格式=情境(WHEN)→行动(THEN)→原因(WHY，一句话)→证据(源文件)。
> **来源**: D3重构(2026-08-14)从86个feedback文件中，属于(a)交易决策类的34个文件里提炼，去重后的当前有效版本(已废弃的历史修正版本不收录，见MIGRATION_LOG.md)。

## §A 选股与建仓方法论

**A1 供给侧优先于需求侧故事**
WHEN 评估一条产业链/一个标的的thesis → THEN 第一镜片是产能瓶颈/物理约束/谁有定价权，需求侧故事不算thesis → WHY A股的选股方法论18条核心 → *astock_screening_sop.md 铁律1*

**A2 中国edge三分判别，概念真≠份额真**
WHEN 研究AI链/国产替代类节点 → THEN 每个公司套"真受益(四件套:份额爬升+客户认证+产能落地+季度兑现)/卡脖子吃不到/伪关联"三分类，最紧瓶颈≠中国吃得到的节点 → WHY 把"瓶颈紧"当成"能赚钱"是最大陷阱(ABF载板全链最紧但国产份额≈0) → *china_edge_paradigm.md F22*

**A3 涨了先问为什么，框架解释不了=框架有盲区**
WHEN 看到标的/板块涨停或大涨 → THEN 第一反应不是"涨太多了"，是"为什么涨？我的产业链地图是不是缺了这个节点？" → WHY 市场是对的，框架是活的；否定市场=选了容易的路 → *astock_methodology.md 核心修正#9*

**A4 主题位置判断：台阶vs尾声，尾声不追**
WHEN 判断某条主题线还能不能追 → THEN 查健康台阶特征(龙头领涨新高+前方有催化+季报超预期) vs 尾声特征(龙头滞涨小票乱涨+弹性最小的票补涨最猛) → WHY 追尾声=接最后一棒 → *astock_screening_sop.md 铁律7, 详细判据见 knowledge_astock_theme_structure.md*

**A5 涨停=建仓信号非阻力，催化剂在前面就该追**
WHEN 标的涨停/大涨后犹豫要不要追 → THEN 问"催化剂在前面还是后面"，不是"今天涨了多少"；催化剂还没兑现=涨停是市场确认thesis是真的 → WHY "等回调"本质是用价格行为否定thesis，和"PE低所以买"同一逻辑错误 → *astock_methodology.md 核心修正#3 + no_wait_pullback.md*

**A6 小票先飞龙头后动，龙头未动=窗口还在**
WHEN 新催化剂出现，某主题小票已经先涨 → THEN 立即查该主题龙头是否已动；龙头未动=机构资金还在路上，仍有入场窗口 → WHY 小票速度快/机构参与少先反应，龙头需要2-3天资金轮动 → *astock_methodology.md 核心修正#7*

**A7 政策信号vs游资接力，只抓能赚到的那类**
WHEN 某板块小票连板 → THEN 判断游资接力(流通盘<50亿+龙虎榜全游资+无政策文件可溯，不碰) vs 政策信号驱动(流通盘>200亿+政策文件可查+机构参与，找龙头) → WHY 04-05月电力行情因为没在政策信号出来当周扫描中大盘龙头而错过 → *astock_methodology.md 核心修正#8*

**A8 龙头崩=板块终，同板块次日全线评估**
WHEN 板块龙头单日大跌≥5%或跌停 → THEN 当天=该主线行情结束，同板块所有持仓次日开盘评估出场，不等自己的止损线；但基本面好不是特例(A股主题股覆巢之下无完卵) → WHY 龙头筹码结构最先恶化，龙头出货=跟风资金必溃散 → *astock_methodology.md R6c*

**A9 建仓双门槛：好走势 + 估值便宜，两个都占**
WHEN 考虑建仓 → THEN 走势(慢牛连续爬升，不追当天大涨/不接见顶链回踩) 和 估值(PEG/前瞻PE有安全边际，非透支高PE) 两条都满足才买；只满足一个不够 → WHY 07-08用户令治频繁交易，"好的走势+便宜的估值"缺一不可 → *position_flexibility.md*

**A10 持有期匹配买入性质，别把追高仓当中线拿**
WHEN 买入决策那一刻 → THEN 定死持有期：埋伏仓(双门槛过关)=长持+基本面止损；追高仓(追动量/估值不便宜)=短持+技术止损，动量没了/破线就走 → WHY 追高的票回撤大，当中线拿必套死 → *position_flexibility.md*

## §B 仓位与执行纪律

**B1 计划外买入 = 违规，写死当日清单是唯一合法买入源**
WHEN 盘中想买清单外的标的 → THEN 触发G7两问断路器，不因"手已经放在下单键上"而跳过 → WHY 80%亏损来自这个瞬间冲动，意志力对付不了0.5秒的冲动，只能靠外部刹车 → *impulse_buy_circuit_breaker.md — 亦见 hardgate G7*

**B2 埋伏仓/probe仓只配基本面止损，不挂T+1技术扳机**
WHEN 建仓性质是"博业绩拐点/深研埋伏" → THEN 只在thesis三问(供给约束/主beta/催化时间线)变坏时才走，禁止挂T+1日内技术止损线 → WHY 德赛"埋伏博业绩拐点"次日破线23被砍半，砍完回买入区锁死损失 → *replay_hold_discipline.md P1*

**B3 判断扭曲4根因：单日结论/挑细节逃避/叙事锚定/规则当挡箭牌**
WHEN 持仓判断纠结不下 → THEN 自检是否踩中：①用单日量比下守卖结论(应看30-60天结构) ②在细节里找不动的借口(应先看大盘regime→板块→个股) ③死抱长期thesis盖过盘面尖叫的-25% ④拿"埋伏仓无止损"规则合理化死扛破线仓 → WHY 07-09用户连续戳穿的4个判断扭曲模式，规则冲突时用"这笔现在还会买吗"裁决，不挑对自己方便的 → *integrated_trend_system.md*

**B4 板块崩时"减仓避险"和"清仓"是两个不同动作，别混**
WHEN R6c龙头崩/板块崩当天，持有A+/A级conviction标的 → THEN 减仓避险(锁利，减半或更多)，但供给侧thesis未破的留底仓守中长期thesis，全清只在thesis真证伪时 → WHY 06-18巨化板块崩全清，06-22涨停证明板块崩是短期恐慌不是thesis破 → *trading_rules.md §7*

**B5 逆势涨该拿住，逆势跌该警惕——别搞反**
WHEN 持仓逆大盘走势 → THEN 逆势上涨=资金涌入=最该拿住的强势信号，不是卖点；逆势下跌才是该减的信号 → WHY 顺络6/15逆势+8.4%被当"礼物级出场"卖飞，错过后续+39%主升 → *trading_rules.md §6*

**B6 Track A的票只按Track A逻辑管，别用Track B信号卖**
WHEN 一只基本面thesis驱动买入的票，市场信号(扫描/涨停/资金)短期消失 → THEN 只因thesis证伪(订单丢/份额掉/技术替代)而卖，不因市场信号消失而卖 → WHY 顺络教训：Track A/B混淆是"发现得到守不住"的根因之一 → *trading_rules.md §6*

**B7 抓到一只先问是不是一条产业链的一环**
WHEN 建仓/发现某标的机会 → THEN 问该票是否属于一条产业链，同链还有谁、谁更上游/壁垒更高，不孤立看单票 → WHY 顺络抓到没上升到"被动元件涨价板块"认知，漏掉国瓷/三环 → *trading_rules.md §6, 详见 knowledge_astock_mainline_warfare.md*

## §C 持有/卖出/复盘纪律

**C1 暴力拉升=止盈窗口，只提醒不默认减**
WHEN 持仓单日涨>8%或2-3日累计>15% → THEN 报告"止盈窗口打开"，仅两种情况执行减仓：①催化剂已兑现 ②涨价资源链见顶；成长主线仓暴涨=趋势确认，持有 → WHY 07-06实盘回测：暴涨减半是60笔样本里最差策略(+5.96% vs 死拿+8.12%) → *这条已被CLAUDE.md T11降级收编，本文件仅记录来源，执行以T11为准 — 源: add_position_gate.md(已废止的旧版) + 交易通用T11*

**C2 卖出制度只认4类预设信号，无信号不卖**
WHEN 判断是否卖出 → THEN 只在①末段暴涨(放量滞涨/长上影浮盈>15%) ②链级见顶(整链天量巨阴) ③催化兑现 ④灾难线-12%这4类信号响时执行，信号响=当天执行不过夜 → WHY 06月卖飞病根=无信号乱卖，07月回吐病根=有信号不执行，两轮回测定版 → *对应CLAUDE.md T11b，本文件仅做背景说明*

**C3 见顶后回踩买回需等真企稳三件套**
WHEN 天量巨阴见顶后考虑逢低接回 → THEN 必须等：跌回见顶价下方≥5% + 量比<0.7缩量 + 收阳，三件套齐才买 → WHY 07-06回测证伪"见顶链回踩作废"的个案立规(2案例就改规则=过拟合)，1880样本证实"缩量回踩企稳买"+5.87%远好于"放量收复前高买"+2.11% → *replay_hold_discipline.md 07-06修正*

**C4 暴跌首日是否清仓要看thesis是否完好，不是看统计**
WHEN 持仓暴跌>7% → THEN A级thesis完好的标的暴跌首日不恐慌清(但守的理由是thesis不是"统计会反弹")；题材/无thesis仓，统计支持首日可以走 → WHY 全市场5472样本统计上首日清仓不算错，但个案(巨化/沪电)清仓后大反弹是另一子集，两者不矛盾 → *replay_hold_discipline.md 07-03修正*

**C5 自设扳机必须严格执行，不许提前行刑**
WHEN 昨天定了明确的量化扳机条件(如"续跌>5%或3日不收复X才动") → THEN 今天条件没触发就不能提前动作，即使方向感觉对 → WHY 北方华创昨定扳机今天两条都没触发就提前清仓，方向未必错但程序错 → *replay_hold_discipline.md*

**C6 涨幅>6%当天禁下"估值T4排除"终判**
WHEN 标的当天涨幅>6%且要做估值判断 → THEN 不能用当日暴涨后的瞬时PE直接下"排除"结论(循环论证)，改"观察-待冷却"，用T+1~3均价重算 → WHY 澜起+40%/长电+47%被trailing PE挡在主升期外(07-01复盘P3) → *replay_hold_discipline.md P3, 对应CLAUDE.md T17*

**C7 A级+供给侧硬约束标的涨停时豁免"涨停不追"**
WHEN A级conviction+管制/矿/认证类物理约束标的涨停 → THEN 涨停=建仓信号，不等回调；等回调仅限B+及以下纯估值分歧，且必设失效期 → WHY 江丰等回调踏空+77.7%，北方华创等回调+57%(回调最深仅-0.3%) → *replay_hold_discipline.md P2, 对应CLAUDE.md T16*

**C8 下结论前先回看自己的历史观点**
WHEN 分析个股/判断持仓/看市场/给任何结论 → THEN 先grep该标的/话题的历史记录(历史扫描裁决/memory/research笔记/交易历史)，连续→增强信心，反转→必须解释为什么变，首次→标"无历史对照" → WHY 防孤立judge、防被单日走势骗、防忘记自己验证过的thesis和教训 → *step2_check_history.md(07-01)*

**C9 Thesis兑现度看"为什么"，不是看"多少"**
WHEN 评估持仓的thesis兑现进度 → THEN 三时间框架(长期结构性/中期当前cycle/短期催化剂情绪)必做，问"为什么涨/为什么跌"优先于"涨了多少/跌了多少"；跌了不等于风险已price in，要找到具体是哪个risk在发生 → WHY v1版本用52周位置机械判断，MOD涨239%但公司本质变了导致旧基准失效 → *thesis_realization.md TRA v2*

**C10 完整扫描必须含交易侧，不能只是选股侧**
WHEN 用户要"完整扫描" → THEN 必须包含买入双确认+卖出5道门+择时+风控+sizing分档，不能只跑选股3步(宏观+产品树+持仓复盘) → WHY 07-16连纠4次：选股侧和交易侧长期是两套脱节系统，报告"只做了持仓" → *full_scan_and_sizing.md — 已代码化进 astock_full_scan.workflow.js*

**C11 sizing按质量分档，不flat**
WHEN 决定新建仓位大小 → THEN 大力满档=probe+放量突破/近突破；小仓半档=probe但timing次一点(放量未突破)；watch=0仓；用深扫的probe裁决定档，机械信号只调档位大小不做0/1闸门 → WHY 两头都错过：机械双确认过严只剩2只建仓，纠正后又flat 9%全建没分档 → *full_scan_and_sizing.md 教训2*

## §D 系统边界与工具纪律

**D1 UASS是发现工具不是建仓入口**
WHEN 使用UASS/扫描系统 → THEN 扫描结果只回答"市场信号有多强"，不回答"该不该买"；有意思的进研究pipeline，研究完成+A-以上才建仓 → WHY 18天实盘：UASS驱动建仓全亏损(-4%~-7%)，研究驱动建仓全盈利(+10%~14%) → *uass_system.md v4.0, system_reset_v12.md*

**D2 UASS报告不含已持仓标的**
WHEN 生成UASS/市场扫描报告 → THEN 五区/信号简报只展示新机会，持仓单独一个板块简洁展示 → WHY 把持仓混进发现区会让报告变成确认偏误工具 → *uass_no_holdings.md*

**D3 A股不做空头评级**
WHEN A股系统做标的评级 → THEN 只做Track A(基本面)+Track B(轮动)两维度，不单独做"做空S级"评级；熊方分析仅用于bear case检查和排除做多universe → WHY A股账户无法做空(融券工具极度有限)，做空分析无实操价值 → *trading_rules.md §1*

**D4 全盘扫描必须覆盖全行业，不能预设主线**
WHEN 执行全市场扫描 → THEN 先铺全行业(申万一级31个不预设主线)，再聚焦全市场龙虎榜，最后按Track A/B评级 → WHY 05-28扫描4个agent全在AI/半导体转，漏掉巨化所在的化工板块，预设主线找标的=确认偏差 → *trading_rules.md §2*

**D5 FOMO换仓触发L10两问硬拦**
WHEN 用户/系统想"换成XX" → THEN 直接硬问"手里那只预期打破了吗？你是不是因为看了别的才想卖？"，不温和列pros/cons → WHY 04-05月实盘9次round trip净亏¥3,260，割掉有催化剂的票换成无催化剂的票 → *trading_rules.md §3*

**D6 复权口径必须主动声明，跨期比较先归一**
WHEN 报告A股历史价格/成本对比 → THEN 声明数据源是不复权(真实成交价)还是前复权(用户软件默认)；跨越送转ex-date的比较必须先按factor归一 → WHY 安集10转3送转事故：不复权314 vs 前复权265对比出假的"26%折扣" → *fuquan_chuquan.md(06-16)*

**D7 材料用量/规模不是投资价值的代理**
WHEN 评估某材料/环节的投资价值 → THEN 价值只由"生意经济性(定价权×增长×毛利) vs 当前价格"决定；小用量+不可替代+垄断供给=最强供给侧thesis不是最弱；没拉价格估值前禁止下"值/不值"判断 → WHY MnO2事故：4.2克用量被拍脑袋判"不成立"，实际标的是多倍股 → *value_not_volume.md(06-16, Constitutional级)*

## §E 系统性诊断（新发现，未完全本地化验证）

**E1 规则族要覆盖"该进攻时进攻"，不能只覆盖"别犯错"**
WHEN 审计/升级交易规则体系 → THEN 检查规则族是否只有防御触发器(暴跌侧止损/止盈/风控)而没有进攻触发器(某板块开始跑赢时N日内建立暴露)；alpha来自选股，beta分层管理(大beta要求高精度、小beta容错) → WHY 08-14美股系统30-agent自审：全部规则族盘点后没有一条负责"顺势而为"，能有效不亏钱但没有机制迫使去赚该赚的钱 → *源: feedback_three_layer_beta.md(08-14) — ⛔这是美股系统的诊断结论，A股规则族(T11b/T18/G1-G15等)是否有同样的"只防御无进攻"缺口尚未做同等审计，建议下次系统体检时对照检查，暂不假定A股也有此病*
