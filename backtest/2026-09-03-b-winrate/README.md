# B策略胜率提升研究 · 2025-01~2026-06 逐笔 (2026-09-03, Buwen: "能不能胜率更高,选更少也行")
样本: B原版每日换手最低3只, 25H1 287笔 / 25H2 375 / 26Q1 168 / 26Q2 171 (共1001笔, 涨停必成交假设同B)。

方法: 17个当日可知特征单条件+两/三条件组合, 要求每期n≥15(三条件≥12), 按"最差期胜率"排(防过拟合)。

明确无效或反向: 市值≥200亿(25H1仅41%) / 成交≥3亿(52%) / 高开>2%(26Q1 59%) / 同行业≥2板不稳(62~80%)。

## 解读
- **"前1日涨>3%"是核心**: 涨停前一天已经在涨(加速形态,不是横盘突发板)——次日溢价四期都高出基线10pp+。
- **"量比<1.5"=缩量板**: 封板不需要放量=抛压小=次日开盘承接好。⚠️但缩量板正是最难排进的板(与09-02可成交性分析冲突): 胜率提升的代价是成交率下降。
- 二三板优于首板(69-85% vs 62-66%), 与龙头验证"高度最重要"一致。
- 笔数: 核心规则每月约8-14笔(vs 基线约50), 选少了但每笔期望翻倍(+4~5% vs +2.5%)。
## 局限
涨停必成交假设未解; 特征在同一样本里筛出再看四期是"半样本外"(条件集是先验列的,组合是穷举的,存在多重比较); 需2026下半年真实跟踪验证。
