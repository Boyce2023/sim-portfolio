# 一进二零容忍独立取证审计报告（QA_1to2_Zero_Tolerance）

> **审计官核心定论**：`audit_old_m2.py` V1 版本砍掉 `TECH_PAT` 后看似仍有 62.4% 胜率、174.56 倍收益的根本原因，**并非该模型依然有效，而是存在三大致命结构性假象：底册幸存者偏差（在旧模型已筛出的 239 笔赢家样本中做消融而非全市场首板盲测）、未剔除一字涨停开盘不可买样本、以及总分 230 刀尖阈值死卡过拟合峰值**。一旦在全市场真实样本中实施严格 Expanding Walk-Forward 滚动盲测，真实净值立即出现断崖式均值回归。

## 一、`audit_old_m2.py` V1 虚假高收益的六大致命问题逐行取证

### 1. 致命缺陷 0：底册幸存者偏差（Sample Selection Bias）——最大的假象来源
- **代码行号**：`audit_old_m2.py:19` 及 `37-40`
  ```python
  LEDGER_PATH = f"{DOCS_DIR}/MASTER_5Y_239_TRADES_LEDGER.json"
  with open(LEDGER_PATH, "r", encoding="utf-8") as f:
      ledger = json.load(f)
  trades = ledger["trades"]
  ```
- **取证事实**：`audit_old_m2.py` 根本**没有读取全市场每日上千只股票的真实首板候选池**！它直接读取的是历史旧模型早已精挑细选出来的 239 笔交易总账 `MASTER_5Y_239_TRADES_LEDGER.json`。
- **虚假根因**：V1 仅仅是在这 239 笔「赢家账本」中，扣除了 `tech_bonus(16分)` 和 `new_term_bonus(15分)`，剩下的 162 笔股票依然是**旧模型用全部未来函数和过拟合规则筛选后的胜者子集**！在赢家堆里消融 1-2 个因子，自然依然体现出 62.4% 的胜率与 174 倍收益。这属于典型的**把已选出的交易记录当做全市场样本空间**的严重口径错误。

### 2. 问题 ①：V1 的打分中是否残留其他静态概念与后视镜因子？
- **取证事实**：
  1. **静态概念残留**：V1 仅扣除了 `is_tech`（16分）和 `has_new_term`（15分）。但原账本的 `s_prior` 里仍然固化了 `elo_rk` 和 `theme_score`（基于静态板块词表 `astock_concept_vocab.json` 对历史数据拟合出的板块热度）。
  2. **公告未来函数残留**：原账本中的 `notice_hard`（18分）在 V1 中完全未剔除。旧版 SQL 允许 `ndate <= d1_date + 4`，即允许将买入日之后最多 4 天内才披露的公告提前计入先验分，V1 依然全盘继承了这一跨期未来函数。

### 3. 问题 ②：离场收益计算与一字跌停锁仓无法卖出
- **代码行号**：`audit_old_m2.py:137-143`
  ```python
  if (tk, exit_d) in df_price.index:
      row_ex = df_price.loc[(tk, exit_d)]
      exit_price = float(row_ex["open"])
      ret_calc = (exit_price / open_p) - 1.0
  ```
- **取证事实**：
  1. 账本中存在连板持有（持有多日直至断板日开盘卖出）。
  2. **完全忽略一字跌停流动性断裂**：在断板日如果开盘即一字跌停（`open == low == high == dt_price`），在真实交易中封死跌停根本无法以开盘价卖出，必须按规则锁仓直至开板。`audit_old_m2.py` 假设所有股票在断板日早盘 09:25 都能 100% 毫无摩擦以 `row_ex["open"]` 顺利离场，抹平了核按钮断板大面的真实亏损。

### 4. 问题 ③：开盘买入是否剔除一字涨停（D2 open >= zt_price）？
- **代码行号**：`audit_old_m2.py:136-145`
- **取证事实**：
  - 代码在 `buy_type == "open"` 分支下，**没有任何判断开盘是否一字涨停的代码**（缺失 `if open_p >= zt_p: continue`）！
  - 经独立脚本比对 239 笔交易，有多只样本开盘直接涨停封死。在真实实盘中，非通道资金根本无法买入一字涨停票，但回测全部按 `open_p` 假装买入，凭空套取了一进二顶一字连板的最丰厚利润。

### 5. 问题 ④：V3 收紧 10% 后交易笔数从 162 暴跌至 39、净值崩塌至 2.36 倍的原因
- **代码行号**：`audit_old_m2.py:372-378`
  ```python
  # 收紧 10%: tot_thr 230 -> 253, s_prior 35 -> 38.5, o_pct [0.033, 0.074], dd20_d0 <= 0.82 * 0.90
  ```
- **刀尖过拟合解剖**：
  - 核心杀手是 `tot >= 253` 与 `s_prior >= 38.5`。原版模型的 239 笔样本中，大量个股的总分密集堆积在 `230 ~ 245` 区间，先验分堆积在 `35 ~ 38` 区间。
  - 参数微调 10% 后，84% 的样本被直接淘汰。这彻底证明原参数 `230` 和 `35` 是在样本内精准剪裁过的「刀尖阈值」（Cliff-edge Threshold），抗扰动性极差，缺乏任何参数平原（Parameter Plateau）。

### 6. 问题 ⑤：全市场 Expanding Walk-Forward 盲测的真实表现
- **对照证据**：参考全市场严格盲测脚本 `clean_walk_forward_1to2.py`（无后视镜、无提前公告、全市场无选样偏差）：
  - 真实的年化超额与胜率立即均值回归至市场常规水平（胜率约 49%~52%，单仓净值处于 1.0~2.5x 之间）。
  - 证明 `audit_old_m2.py` 中的 174 倍累计净值完全是**幸存者底册 + 一字开盘假成交 + 刀尖过拟合**堆砌出的数字幻象。

## 二、后续工程整改底线结论

1. 严禁基于 `MASTER_5Y_239_TRADES_LEDGER.json` 做任何消融或有效性评估，必须以全市场每日首板作为候选池。
2. 必须在所有回测中增加 `if open >= zt_price: continue` 强制剔除一字不可买样本。
3. 卖出端必须加入跌停锁仓检测：若卖出日一字跌停则强制顺延至开板日卖出。
4. 因子打分与选股阈值必须走严格 Expanding Walk-Forward，严禁全周期静态切分硬门槛。
