结论:
1. **前两天的信息没有增益,加进去整体是负的**: 全基石版三月累计+107% vs 原版+173%。
2. **A(换手自适应)是主要拖累**——三个月全负(Jan -16pp/Feb -3pp/Mar -8pp)。"前两天高换手组溢价高→今天按高换手排"这个规则在样本外不成立: 换手与次日溢价的关系两天内不持续。⛔今晨"缩圈日高换手板更好"的假设被这组数据否定(至少以两日记忆的形式)。
3. **S(板块延续)方向不稳**: 1/2月拖累,3月+8.6pp增益——只在主线清晰的月份有用,不能常开。
4. **M情绪基石基本不触发**(前两日溢价均值几乎从不≤0),等于没用。H轻微负。
5. B的alpha来自"当天板→次日开盘溢价"本身,记忆窗口越长噪音越多。要改B,方向不在"看前两天",在"可成交性"(见09-02 baserate分析)。
⚠️同B原版一样受涨停必成交假设影响,读方向不读绝对收益。
