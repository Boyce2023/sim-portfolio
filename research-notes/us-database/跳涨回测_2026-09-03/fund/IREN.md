# IREN IREN Ltd.

- 干什么的: 自建数据中心+租GPU算力给AI公司(Neocloud模式),同时自己也做加密货币挖矿(比特币),现在业务重心快速转向"AI Cloud Services"——即拿地/建电/装GPU/租给客户跑AI训练推理,自称做电网到软件全栈(data center+compute+软件Mirantis)。
- 所在链条位置: (类别: 七 Neocloud/GPU云) 上游是英伟达GPU供应+电力/土地/变电站基建,下游是AI公司客户(Cohere/Prometheus/Perplexity/Figure AI/Fal.ai/Higgsfield AI及一家未披露的frontier lab,以及微软/英伟达的算力承购),同类对手是CoreWeave等其他Neocloud/GPU云厂商。
- 最近一季关键数字(F4Q26即FY2026Q4, 8月27日发布/电话会同日,来自研报+call): EBITDA仅$19mn,大幅低于GS预期$33mn和市场一致预期$57mn;AI Cloud Services营收$71mn,高于GS的$56mn但低于市场一致$88mn。2026年已签约合同ARR达$4bn(其中$1bn已在运营),FY2027资本开支指引上调到$25-30bn(中值$27.5bn),其中约$14bn已有微软GPU融资/预付款覆盖,另需约$8bn的GPU质押融资,剩余约$5.5bn需靠公司债/数据中心抵押债/股权融资。GS给出的营收预测(非公司指引): FY6/26 $707mn → FY6/27E $2,755mn → FY6/28E $7,475mn,增速极快但EPS长期为负(FY6/27E EPS -$4.01)。
- 现在的核心争论: 多头讲的是"物理世界建不快,数字世界扩张太快"的结构性缺口故事——2026年产能已基本卖完,2027/2028产能在密集签约中,且自己拥有数据中心+GPU+软件三层全栈,议价权比只租一层的同行强;空头担心的是本季EBITDA和AI云收入双双不及一致预期,叠加$25-30bn的天量资本开支需要外部融资填坑(净负债/EBITDA预测到FY6/27高达13.5倍),现金流长期为负(FY6/27E自由现金流-$24bn),属于"讲故事快、烧钱更快"的高杠杆扩张模式。
- 增长驱动与最大风险: 驱动=AI算力需求爆发式增长(管理层引用OpenRouter数据称8个月token使用量涨近17倍)叠加公司自身产能持续上量(目标2026年交付0.3GW-IT、2027年0.8GW-IT)。风险=融资端: 尚有约$5.5bn资本开支缺口未落实融资方式,且净负债/EBITDA已处高位,一旦GPU租赁需求或定价不及预期,重资产+高杠杆的模式会放大下行风险。
- 高盛评级/目标价: Neutral(中性)评级,12个月目标价$50(卖方观点),财报当天收盘价$40.53,隐含上行23.4%。
- 我的一句话判断(初步): 这是一门"重资产+高杠杆押注AI算力需求持续爆发"的生意,故事性强、客户名单和融资能力都还不错,但本季度业绩已经开始不及预期(EBITDA大幅miss),且未来两年现金流会持续大幅为负,现在处在"产能疯狂扩张、盈利兑现远未到来"的早中期阶段,风险回报不对称,值得盯但不算稳。
