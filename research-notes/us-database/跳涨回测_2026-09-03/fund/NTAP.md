# NTAP NetApp

- 干什么的: 卖企业级数据存储硬件(全闪存阵列)和云存储服务(Public Cloud、Keystone存储即服务), 客户是企业和政府IT部门, 靠卖存储设备+订阅式云存储/支持服务赚钱。
- 所在链条位置: (类别: 三 存储) 处在企业数据基础设施层, 定位是"混合云智能数据基础设施"——把本地存储和AWS/Azure/Google Cloud打通, 帮企业的AI应用调用自己的数据。上游依赖闪存/内存等元器件(受memory涨价影响), 下游客户是大型企业/政府机构/新型云厂商(neo-cloud); 与Google Cloud、AWS(FSx for NetApp ONTAP)、Azure是合作关系而非纯竞争。无研报, 竞争对手未在call中点名。
- 最近一季关键数字(FY2026Q4, 来自call): 营收19.5亿美元, 同比+12%, 环比+14%; 非GAAP EPS $2.43, 同比+26%; 全年FY26营收69.3亿(+5%, 剔除已剥离的Spot业务后+7%); 全年营业利润率30.2%(创纪录); Public Cloud收入全年6.88亿(+18%); 全闪存全年42亿(+11%); Keystone(存储即服务)全年增长约65%。FY27指引: 营收73.25-75.75亿区间(中值+8%同比, 较FY26的5%增速加快), EPS指引$8.70-9.00, 承诺FY27最高100%自由现金流返还股东。
- 现在的核心争论(初步推断, call中未直接呈现空头声音): 多头讲——AI时代"瓶颈不是算力是数据激活", NetApp独家做到本地+多云统一数据治理(zero-copy), Q4靠Google Cloud大单和Keystone、全闪存驱动创纪录利润率, FY27指引加速增长; 空头担心点(call未明说, 存疑)可能是memory/元器件成本上涨挤压产品毛利率(call中提到"managing rising memory and component costs"), 以及存储硬件行业本身增长天花板较低(个位数增速)。
- 增长驱动与最大风险: 驱动是AI带来的"数据激活"需求(2026财年AI相关成交超1100单)叠加Keystone订阅制转型和与Google/AWS/Azure的云集成大单。最大风险是memory等元器件成本上涨压缩产品毛利率(call中CFO明确提到这一压力, FY27毛利率指引68.5-69.5%, 低于FY26的71.3%)。
- 高盛评级/目标价: 无研报, 未获取。(卖方观点缺失)
- 我的一句话判断(初步): 这是一门稳健但不性感的生意, 增速从5%提到8%指引不算爆发式, 更多是"AI浪潮里搭便车的传统存储厂商"而非核心受益标的, 需要看有没有研报佐证估值是否已经price in这个加速。
