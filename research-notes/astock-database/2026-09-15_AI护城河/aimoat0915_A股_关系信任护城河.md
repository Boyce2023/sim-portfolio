## 逐只小节

### 1. 用友网络 600588 — 结论：强

- **护城河**：客户是国有大型企业与集团公司的ERP/BIP核心系统，替换成本极高——停业务、重新培训、数据迁移风险。半年报披露"累计替换300多家大型企业使用的国际厂商系统"，说明护城河不仅稳固还在从SAP/Oracle手里抢存量客户。
- **收费模式与AI加减法**：主体是云服务订阅(云服务收入28.9亿，占营收77.5%)，不是按人头计费的实施外包，AI模块(BIP本体智能体、YonLOM大模型、YonClaw超级智能体)作为存量客户的加售项，是加法。
- **AI怎么变成钱**：AI相关合同签约与AI相关收入直接在半年报中单列披露。
- **最近两季兑现证据**：2026年半年报（600588，2026-08-22披露）：AI相关合同签约金额9.06亿元，AI相关收入4.64亿元；大型企业客户业务收入23.8亿元，同比+2.8%。来源：[每经网 2026-08-21](https://www.nbd.com.cn/articles/2026-08-21/4550208.html)、半年报原文PDF [新浪财经](http://file.finance.sina.com.cn/211.154.219.97:9494/MRGG/CNSESH_STOCK/2026/2026-8/2026-08-22/12516529.PDF)。
- **反面风险**：①整体营收增速仅4.1%，云服务增速也只有4.6%，AI收入4.64亿相对37.27亿总营收占比仍小(约12.4%)，尚未成为增长主引擎；②PE_TTM为负(-23.34)，说明过去12个月公司整体是亏损的，估值锚点不稳，靠远期AI叙事支撑股价的风险大。
- **估值快照**：收盘9.38元 / PE_TTM -23.34（亏损） / PB 4.77 / 总市值320.51亿（2026-09-15收盘，腾讯行情接口）。

### 2. 税友股份 603171 — 结论：强

- **护城河**：与国家税务系统深度绑定，承建金税四期新电局、税智撑、自然人电子税务局等官方基础设施，服务全国7亿多自然人、5000多万扣缴单位——这是牌照/官方基础设施级别的关系护城河，不是普通软件客户粘性能比的。
- **收费模式与AI加减法**：数智财税+数字政务的SaaS/订阅回款模式，不靠人头/实施人力堆砌，AI产品(财税Agentic)是在存量订阅基础上的增值加售，是加法；报告明确给出"AI产品及业务回款占比突破三成(33%)"这个可验证指标。
- **AI怎么变成钱**：财税Agentic 2.0，AI回款嵌入现有SaaS订阅体系单独计费。
- **最近两季兑现证据**：2026年半年报（603171，2026-08-26披露）：营收10.12亿元+9.72%，归母净利润9400.46万元+32.38%；数智财税业务收入7.14亿元+14.99%，AI产品及业务回款占比33%。来源：[21世纪经济报道 2026-08-26](https://www.21jingji.com/article/20260826/herald/5249563c5daea1e2493cb85b72f5698b.html)。公司目标是2026年子品牌"亿企赢"AI驱动营收占比达50%（[中国金融信息网 2026-06-14](https://www.cnfin.com/cmjj-lb/detail/20260614/4426392_1.html)，属前瞻目标不是已兑现数字，未计入结论）。
- **反面风险**：①"AI产品及业务回款占比33%"这个口径披露不够透明——不清楚33%是AI产品单独收入还是"AI相关+原有产品捆绑"的模糊口径，需要进一步拆分验证；②PE_TTM 98.83明显偏贵，隐含高增长预期已经price in，一旦AI回款增速不及预期，估值回撤风险大；③税务信息化行业高度依赖政府预算与招标节奏，政策/财政周期波动会直接影响订单节奏。
- **估值快照**：收盘38.73元 / PE_TTM 98.83 / PB 6.15 / 总市值157.38亿（2026-09-15收盘，腾讯行情接口）。

### 3. 中控技术 688777 — 结论：中

- **护城河**：客户是石化、化工等流程工业企业，DCS(集散控制系统)是安全关键系统，一旦部署几乎不会中途更换——停产改造的风险和成本远超软件采购成本，公司核心产品市占率连续15年行业第一。
- **收费模式与AI加减法**：传统主业含大量工程集成/实施服务(人力密集)，这部分理论上会被AI自动化调试压缩，是潜在减法区；但工业AI(TPT大模型)业务已经从"一次性买断"转向MaaS/RaaS订阅式"结果即服务"收费，这是明确的加法新收入线，且有股权激励目标(2026年工业AI收入10亿元)背书。
- **AI怎么变成钱**：TPT时序大模型+通用控制系统UCS融合的工业具身智能系统，按订阅/效果付费。
- **最近两季兑现证据**：2026年一季报：工业AI业务收入1.84亿元，占一季度营收15.06亿元的12.2%（[10jqka 2026-04-27](https://news.10jqka.com.cn/20260427/c676291583.shtml)）。2026年半年报（2026-08-29披露）：营业收入36.35亿元，同比下降5.10%；归母净利润1.55亿元，同比下降56.20%（[凤凰网 2026-08-29](https://i.ifeng.com/c/8vxkJSrCUzO)）；半年报未单独披露H1工业AI收入具体数字（仅一季报披露过1.84亿）。作为对照，2025年上半年工业AI产品TPT收入为1.17亿元（[中证网 2025-08-29](https://www.cs.com.cn/ssgs/gsxw/202508/t20250829_6510086.html)），显示AI收入同比在增长，但增长掩盖不了公司整体盈利大幅恶化。
- **反面风险**：①2026H1整体净利润同比腰斩(-56.2%)，AI业务放量的同时主业(控制系统集成)在明显承压，说明"AI加法"目前不足以对冲传统业务下滑；②PE_TTM高达277.38，在净利润暴跌的背景下估值极贵，隐含市场对AI转型的乐观预期已经充分price in，一旦2026年工业AI收入不能触及10亿元目标，估值有大幅回撤风险。
- **估值快照**：收盘85.01元 / PE_TTM 277.38 / PB 6.83 / 总市值672.59亿（2026-09-15收盘，腾讯行情接口）。

### 4. 金证股份 600446 — 结论：中

- **护城河**：客户是证券公司、交易所的核心交易/清算系统，属于金融基础设施级别，切换成本和监管审批门槛都极高。
- **收费模式与AI加减法**：传统金融IT收费模式以项目制/定制开发人力为主，这部分正是AI压缩的重灾区(自动化代码生成、需求分析压低人天报价)——是减法风险区；但公司明确把AI增值服务从项目制拆出来单独订阅收费(智能条件单解决方案，2025Q4起在多家券商上线)，这是主动对冲减法的加法动作。
- **AI怎么变成钱**：K-GPT金融大模型+K-Code代码大模型，智能条件单AI增值服务单独收费，从买断转向订阅制。
- **最近两季兑现证据**：2026年半年度业绩预告（2026-07-13，[上海证券报](https://paper.cnstock.com/html/2026-07/14/content_2243301.htm)）：预计归母净利润1320.35万元~1961.11万元，实现扭亏。公开报道称"智能条件单解决方案已实现AI增值服务单独收费，网格单新客户自然增长率提升50%"（[新浪财经 2026-06-10](https://finance.sina.com.cn/wm/2026-06-10/doc-iniaxkrr4492517.shtml)），但未找到具体AI收入或AI收费金额的一手数字披露——**这是"叙事有，数字未单列"的典型情况，兑现证据强度弱于用友/税友**。
- **反面风险**：①PE_TTM为-83.40，说明过去12个月整体仍是亏损状态，H1的小额盈利预告尚不足以扭转趋势；②AI增值服务收入没有具体数字披露，无法验证AI对业绩反转的实际贡献比例，存在"讲AI故事、真实收入贡献有限"的可能性；③证券IT高度依赖资本市场景气度和券商IT预算，2026年若市场交投清淡，订单节奏会受冲击。
- **估值快照**：收盘10.36元 / PE_TTM -83.40（亏损） / PB 2.72 / 总市值97.52亿（2026-09-15收盘，腾讯行情接口）。

### 5. 恒生电子 600570 — 结论：中

- **护城河**：客户是券商、基金、资管公司的核心交易/估值/清算系统，在国内金融IT里接近垄断地位，切换成本极高（涉及监管报送、历史数据迁移、交易连续性风险）。
- **收费模式与AI加减法**：与金证类似，传统金融IT收费依赖项目实施人力，是AI减法的风险区(市场上有报道称公司2025年减员约2200人，[CSDN博客 2025年](https://blog.csdn.net/ZPWhPdjl/article/details/147914367)，二手信息未经一手公告验证，仅作为佐证减法风险的旁证)；LightGPT大模型、WarrenQ智能投研平台是加法方向，指引称2026年AI业务预计增速70%。
- **AI怎么变成钱**：LightGPT金融大模型(部署20+机构，含东方证券、华泰证券)、WarrenQ智能投研订阅、Photon智能助手。
- **最近两季兑现证据**：2026年半年度业绩预告（2026-07-14）：预计营收21.44亿元，同比下降11.64%；归母净利润2.62亿元，同比增长0.69%；扣非净利润2.10亿元，同比增长9.30%（[中财网](https://www.cfi.net.cn/p20260715002245.html)）。**未找到2026半年报中AI相关收入的具体披露数字**——公开信息只有对2026全年AI业务增速70%的前瞻指引，属于叙事层面，不满足"最近两季财报里能看到AI带来的钱"这条硬标准，故评级压低到"中"。
- **反面风险**：①营收同比下降11.64%，公司自己解释为"项目验收周期拉长"，也可能是传统项目制业务被AI/降本压力挤压的信号；②没有找到AI收入具体数字，无法排除"AI叙事强、实际收入贡献未知"的可能；③金融IT全行业(金证、宇信、长亮)2025-2026年普遍出现营收/净利承压，说明行业性压力不只是恒生一家的问题。
- **估值快照**：收盘20.18元 / PE_TTM 31.03 / PB 3.93 / 总市值382.14亿（2026-09-15收盘，腾讯行情接口）。

### 6. 广联达 002410 — 结论：弱

- **护城河**：客户是建筑施工企业与造价工程师，工程计价数据库和长期使用习惯形成切换成本，属于典型的行业数据+关系护城河。

- **估值快照**：收盘8.37元 / PE_TTM 37.54 / PB 2.36 / 总市值138.27亿（2026-09-15收盘，腾讯行情接口）。

## 最强1到2只及原因

**用友网络(600588)、税友股份(603171)**

两家共同点：①护城河都不是靠人头收费——用友是云订阅+大型客户合同制，税友是SaaS+政府基础设施绑定，AI在这两种商业模式里天然是"加售"而不是被AI替代的人力成本；②都在最近一期半年报里给出了**具体、可验证的AI收入/回款数字**（用友4.64亿AI相关收入，税友33%AI产品回款占比），不是停留在发布会/目标层面的叙事。相比之下中控技术虽然AI收入增长快，但公司整体净利润腰斩(-56.2%)，说明AI放量尚未能对冲主业压力；金证、恒生电子的AI故事都还没有拆出具体收入数字。
